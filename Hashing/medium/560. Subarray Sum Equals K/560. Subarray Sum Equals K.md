## 560. Subarray Sum Equals K

- Given an array of integers nums and an integer k, return the total number of subarrays whose sum equals to k.


**Eg:**

```
Input: nums = [1,1,1], k = 2
Output: 2
```


### Approach

- Use prefix sum to solve this problem.
- Look at the following example:

```
arr=[1,2,3,4]
sum at index 0 = 1
sum at index 3 = 10

difference between sum at 3 and sum at 0 gives the window sum between that particular section.
```


- Use a map to store the sum and their frequencies, because we have to calculate the number of windows whose window sum is k.
- Track the curr_sum of the elements in the array , and check if it has occured already in the array anywhere.
- Keep track of the frequency of curr_sum, and also keep a count variable to track of how many times you have noticed the windowsum of k.
- Return the count.


```java
for (int i = 0; i < n; i++) {
            curr_sum += nums[i];

            if (map.containsKey(curr_sum - k)) {
                count += map.get(curr_sum - k);
            }

            map.put(curr_sum, map.getOrDefault(curr_sum, 0) + 1);
        }

        return count;
```
