## 404. Sum of Left Leaves

- Given the root of a binary tree, return the sum of all left leaves.
- A leaf is a node with no children. A left leaf is a leaf that is the left child of another node.

**Eg:**

<img width="277" height="302" alt="image" src="https://github.com/user-attachments/assets/f2dd7b59-33e5-4957-9bb9-4364fa377550" />

```
Input: root = [3,9,20,null,null,15,7]
Output: 24
Explanation: There are two left leaves in the binary tree, with values 9 and 15 respectively.
```

### Approach

- We have to return the sum of all left leaves of the tree.
- When a root has rootleft==null && root.right==null, it is a leaf node.
- Keep a variable sum, for calculating the sum.
- Recursively call the given function for root.left & root.right.



```java
if (root.left != null && root.left.left == null && root.left.right == null) {
            sum += root.left.val;
        }

        return sum + sumOfLeftLeaves(root.right) + sumOfLeftLeaves(root.left);
```
