## 338. Counting Bits

- Given an integer n, return an array ans of length n + 1 such that for each i (0 <= i <= n), ans[i] is the number of 1's in the binary representation of i.

**Eg:**

```
Input: n = 2
Output: [0,1,1]
Explanation:
0 --> 0
1 --> 1
2 --> 10
```

### Approach

- Use a dp array, where dp[i] stores number of set bits in i.
- For counting number of set bits in i, use Brian kerninghan's algorithm.

```
dp[i] = dp[i&(i-1)] + 1;
```


### Time & Space Complexity

- **Time Complexity** : O(n)
- **Space Complexity** : O(n)
