## 118. Pascal's Triangle

- Given an integer numRows, return the first numRows of Pascal's triangle.
- In Pascal's triangle, each number is the sum of the two numbers directly above it as shown:

<img width="381" height="368" alt="image" src="https://github.com/user-attachments/assets/3dcc3dbe-e47e-4780-9d3c-9f6e6d3a6c4d" />


**Eg:**

```
Input: numRows = 5
Output: [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]
```

### Approach

- At each row, we calculate the current row elements using the previous row elements.
- Use a nested loop to fill the elements of the current row using elements from previous row.
- Initialize 0 at starting and ending of every row.
- For every other index calculate the value like this:
```
list.add(list.get(j)+list.get(j-1));
```
