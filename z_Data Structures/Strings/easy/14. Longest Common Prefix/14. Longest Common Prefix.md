## 14. Longest Common Prefix

- Write a function to find the longest common prefix string amongst an array of strings.
- If there is no common prefix, return an empty string "".

**Eg:**

```
Input: strs = ["flower","flow","flight"]
Output: "fl"
```


### Approach

- Suppose a string as the prefix, say strs[0].
- Traverse through the array, check whether it is the prefix of the strings or not.
- As long as it is not the prefix of the strings, decrement its length, and remove a character and check for the recurring strings.

```java
for (int i = 0; i < strs.length; i++) {
            while (!strs[i].startsWith(prefix)) {
                n--;
                prefix = prefix.substring(0, n);
            }
            if (prefix.isEmpty()) {
                return "";
            }
        }
```
