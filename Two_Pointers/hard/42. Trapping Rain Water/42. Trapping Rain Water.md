## 42. Trapping Rain Water

- Given n non-negative integers representing an elevation map where the width of each bar is 1, compute how much water it can trap after raining.

**Eg:**

```
Input: height = [0,1,0,2,1,0,1,3,2,1,2,1]
Output: 6
Explanation: The above elevation map (black section) is represented by array [0,1,0,2,1,0,1,3,2,1,2,1]. In this case, 6 units of rain water (blue section) are being trapped.
```

### Approach

- We have to calculate the total amount of water stored in the elevation.
- The total amount of water trapped is equal to sum of water stored at each bar.
- Water stored at each bar is based on its leftMax element and rightMax element.
- A bar with greater height to its left and right ,decides how much water can be stored at each bar.
- After calculating that water, we will add every unit and then return it.


```java
 for (int i = 1; i < n; i++) {
            left[i] = Math.max(height[i], left[i - 1]);
        }

        for (int i = n - 2; i >= 0; i--) {
            right[i] = Math.max(height[i], right[i + 1]);
        }

        for (int i = 0; i < n; i++) {
            water += Math.min(left[i], right[i]) - height[i];
        }
```
