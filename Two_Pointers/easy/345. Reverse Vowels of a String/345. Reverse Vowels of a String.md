## 345. Reverse Vowels of a String

- Given a string s, reverse only all the vowels in the string and return it.
- The vowels are 'a', 'e', 'i', 'o', and 'u', and they can appear in both lower and upper cases, more than once.

**Eg:**

```
Input: s = "IceCreAm"

Output: "AceCreIm"

Explanation:

The vowels in s are ['I', 'e', 'e', 'A']. On reversing the vowels, s becomes "AceCreIm".
```

### Approach 

- Use two pointers to solve this problem.
- Place the two pointers at the starting and ending of the string.
- And as long as you dont find a vowel, do left++ and right--.
- After you find vowels at right and left, swap them and repeat the process for the remaining string also.



```java
while (left <= right) {

            while (left < right && !isVowel(str[left])) {
                left++;
            }

            while (left < right && !isVowel(str[right])) {
                right--;
            }

            if (left < right) {
                char temp = str[left];
                str[left] = str[right];
                str[right] = temp;
                left++;
                right--;
            } else {
                break;
            }
        }

```
