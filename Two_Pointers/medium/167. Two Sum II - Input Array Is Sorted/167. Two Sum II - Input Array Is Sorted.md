## 167. Two Sum II - Input Array Is Sorted

- Given a sorted integer array numbers and a target value, we have to return the indices of 2 numbers that add up to the target value.
- We should return it in the form of(i+1, j+1) which indicates its location , not index.
- The same element cannot be used twice.


**Example**:

```
Input: numbers = [2,7,11,15], target = 9
Output: [1,2]
Explanation: The sum of 2 and 7 is 9. Therefore, index1 = 1, index2 = 2. We return [1, 2].
```

### Approach

- Use two pointers to solve this question
- Use 2 pointers left, right each starting from beginning and ending of the array.
- Find sum of numbers at left and right at each iteration,
  - if the sum equals the target, return an array [left+1, right+1]
  - if sum becomes greater than the target value, which means we have taken a larger element, we do right--.
  - if sum becomes lesser than target, we do left++.
 

### Time and Space Complexities

- **Time Complexity** : O(n).
- **Space Complexity** : O(1).
