## 15. 3Sum

- Given an integer array `nums` such that return all the triplets nums[i], nums[j] and nums[k] such that nums[i]+nnums[j]+nums[k] == 0.
- You have to return the unique triplets.


**Eg**:

```
Input: nums = [-1,0,1,2,-1,-4]
Output: [[-1,-1,2],[-1,0,1]]
Explanation: 
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0.
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0.
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0.
The distinct triplets are [-1,0,1] and [-1,-1,2].
Notice that the order of the output and the order of the triplets does not matter.
```


### Approach

- We need to find the three numbers in the given array that sum upto 0.
- We need to skip duplicates too, so if we sort the array, half our job is done.
- Now, we need triplets that sum upto 0, if we fix one element then we are left with 2, for that 2 elements we can use that binary search approach that we do to solve 2sum(when input array is sorted).
- We keep on doing this for every element, and whenever we find such triplets, we would add their values(not indices) as a list into a list.
- Everytime we get a valid triplet, after we are putting it into a list, we need to move forward by doing `start++` and `end--`.
- And also whenever we find duplicates i.e., `nums[start]==nums[start+1], start++` and `if(nums[end] == nums[end-1]) end--`.


```java
for (int i = 0; i < n; i++) {

            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }
            start = i + 1;
            end = n - 1;
            int x = nums[i];
            while (start < end) {
                sum = x + nums[start] + nums[end];
                if (sum == 0) {
                    res.add(new ArrayList<>(List.of(x, nums[start], nums[end])));

                    while (start < end && nums[start] == nums[start + 1])
                        start++;
                    while (start < end && nums[end] == nums[end - 1])
                        end--;

                    start++;
                    end--;
                } else if (sum > 0) {
                    end--;
                } else {
                    start++;
                }
```
