## 75. Sort Colors

- Given an integer array nums, containing 3 colors red, white or blue, which are labelled as `0`, `1` and `2` respectively.
- You should sort them in the order such that, objects of the same colors are adjacent.
- They should be in arranged in the following order: red, white and blue.
- You should not use the library sort function.


**Eg:**

```
Input: nums = [2,0,2,1,1,0]
Output: [0,0,1,1,2,2]
```
```
Input: nums = [2,0,1]
Output: [0,1,2]
```

### Approach

- You should use the counting sort logic here.
- Store the frequenices of all the elements of the nums array in a seperate array, which is 0 indexed, and using that frequency value you should rewrite the nums elements based from beginning.
- We decrement the count at eac index and update the element value in nums.
- In this way, we end with a sorted array at the end.


```java
int idx = 0;
        for (int i = 0; i < count.length; i++) {
            while (count[i]-- > 0) {
                nums[idx++] = i;
            }
        }
```
