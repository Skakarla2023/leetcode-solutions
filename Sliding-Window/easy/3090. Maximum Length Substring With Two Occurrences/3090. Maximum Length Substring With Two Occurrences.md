## 3090. Maximum Length Substring With Two Occurrences

- Given a string s, return the maximum length of a substring such that it contains at most two occurrences of each character.

**Eg:**

```
Input: s = "bcbbbcba"

Output: 4

Explanation:

The following substring has a length of 4 and contains at most two occurrences of each character: "bcbbbcba".
```


### Approach

- Use variable size sliding window.
- Use a hashmap to store the freq of chars as you traverse.
- if any of the chars have freq greater than 2, increment left pointer until the curr chars frequency is <=2.
- While doing so, calculate the length and maxlength.


### Time & Space Complexity

- **Time Complexity** : O(n^2)
- **Space Complexity** : O(n)
