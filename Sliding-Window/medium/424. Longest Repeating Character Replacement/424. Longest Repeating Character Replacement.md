## 424. Longest Repeating Character Replacement

- You are given a string s and an integer k. You can choose any character of the string and change it to any other uppercase English character. You can perform this operation at most k times.
- Return the length of the longest substring containing the same letter you can get after performing the above operations.

**Eg:**

```
Input: s = "ABAB", k = 2
Output: 4
Explanation: Replace the two 'A's with two 'B's or vice versa.
```


### Approach

- We use sliding window to solve this problem.
- We use an array to store the frequencies of the letters in the string.
- Instead of parsing the entire string, we use 2 pointers left, right and check for valid characters,and when we don't find a valid character, we moce our left forward.
- We check the validity of a substring using the following formula :

- update the maxFreq and maxCount as we go forward.



```java
for (int right = 0; right < n; right++) {
            char curr = s.charAt(right);
            letters[curr - 'A']++;

            maxFreq = Math.max(maxFreq, letters[curr - 'A']);

            if ((right - left + 1) - maxFreq > k) {
                char leftChar = s.charAt(left);
                letters[leftChar - 'A']--;
                left++;
            }

            maxLen = Math.max(maxLen, right - left + 1);

        }
```


### Time & Space Complexity

- **Time Complexity** : O(1)
- **Space Complexity** : O(n)
