## 567. Permutation in String

- **Pattern:** Fixed-Size Sliding Window
- **Difficulty:** Medium

**Eg:**

```text
Input: s1 = "ab", s2 = "eidbaooo"
Output: true

Explanation:
s2 contains one permutation of s1 ("ba").
```

---

## Intuition

A permutation must have the **same characters with the same frequencies**. Instead of generating all permutations, we slide a window of size `s1.length()` over `s2` and compare character frequencies.

---

## Approach

1. Create two frequency arrays of size 26:
   - `s1Counts` → frequency of characters in `s1`
   - `windowCounts` → frequency of characters in the current window of `s2`
2. Fill both arrays for the first window.
3. If the arrays match, return `true`.
4. Slide the window:
   - Add the new character.
   - Remove the old character.
5. After each slide, compare the frequency arrays.
6. If they match, return `true`; otherwise, return `false`.

---

## Java Solution

```java
class Solution {
    public boolean checkInclusion(String s1, String s2) {

        if (s1.length() > s2.length())
            return false;

        int[] s1Counts = new int[26];
        int[] windowCounts = new int[26];

        for (int i = 0; i < s1.length(); i++) {
            s1Counts[s1.charAt(i) - 'a']++;
            windowCounts[s2.charAt(i) - 'a']++;
        }

        if (Arrays.equals(s1Counts, windowCounts))
            return true;

        for (int i = s1.length(); i < s2.length(); i++) {
            windowCounts[s2.charAt(i) - 'a']++;
            windowCounts[s2.charAt(i - s1.length()) - 'a']--;

            if (Arrays.equals(s1Counts, windowCounts))
                return true;
        }

        return false;
    }
}
```

---

## Time & Space Complexity

- **Time Complexity:** $\mathcal{O}(n)$
- **Space Complexity:** $\mathcal{O}(1)$

---

## Key Takeaways

- Fixed-size sliding window.
- Compare frequency arrays instead of generating permutations.
- Update only the incoming and outgoing characters while sliding.
