## 3. Longest Substring Without Repeating Characters

- Given a string s, find the length of the longest substring without duplicate characters.

**Eg:**

```
Input: s = "abcabcbb"
Output: 3
Explanation: The answer is "abc", with the length of 3. Note that "bca" and "cab" are also correct answers.
```


### Approach

- Use sliding window and Hashset to solve this problem.
- Use a hashset to store the unique characters.
- Use two pointers left and right, one(right) to add elements into the set, and the other(left) to remove duplicates from the set.
- Update the length everytime you get a new char - `right-left+1`.
- Return the maximum length that you found.


```java
for (int right = 0; right < s.length(); right++) {
            while (set.contains(s.charAt(right))) {
                set.remove(s.charAt(left));
                left++;
            }
            set.add(s.charAt(right));
            maxLen = Math.max((right - left + 1), maxLen);
        }
```



### Time & Space Complexity

- **Time Complexity** : O(n^2)
- **Space Complexity** : O(n) (as we used a hashset)
