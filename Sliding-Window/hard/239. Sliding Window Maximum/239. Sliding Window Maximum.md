## 239. Sliding Window Maximum


- **The Setup (First In)**: When the queue is empty, the current index goes right in. It waits there as a candidate for the maximum value until something else happens.
- **The Clean Out (The While Loop):** As we move forward, the while loop checks if the new element is bigger than what we already have. If it is bigger, we throw away the smaller, useless elements from the back because they can never be the maximum anymore.
- **The Slide Check (The Left Boundary)**: On every single step, we use i - k + 1 to see if our oldest element has been left behind by the moving window. If it is too far left, we kick it out from the front.
